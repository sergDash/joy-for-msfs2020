# AGENTS.md

## Проект

Виртуальный джойстик для Linux, для игры в MSFS-2020.

## Требования

- Минимальный код на C.
- Ввод: `evdev` (чтение клавиатуры). Вывод: `uinput` (виртуальный джойстик).
- 4 оси: X, Y, Z — поверхности самолёта; 4-я — тяга (throttle).
- Оси запоминают положение, пока запущена программа (значение не сбрасывается).
- Реагировать только на нажатие клавиши (EV_KEY down). Удержание и автоповтор игнорировать.

## Таблица кнопок (уменьшить / сброс / увеличить)

| Ось     | Уменьшить | Сброс | Увеличить |
|---------|-----------|-------|-----------|
| X       | Num4      | Num5  | Num6      |
| Y       | Num8      | Num7  | Num2      |
| Z       | Num1      | Num7  | Num3      |
| Throttle| Num0      | —     | NumDel    |

Клавиши задаются по именам `KEY_*` из `linux/input-event-codes.h` (например, `KEY_KP4`).

## Конфиг

- Расположение: ~/.config/joy-for-msfs2020/key.map
- Файл конфига описывает таблицу «клавиша → команда» (например, `KEY_W x_axis_up`).
- Несколько клавиш могут управлять одной осью (WASD-подобные схемы).
- Логика выбора команды идёт строго по этой таблице — не хардкодить раскладку в коде.
