# joy-for-msfs2020

Виртуальный джойстик для Linux, для игры в MSFS-2020. Управляется с Numpad.

## Сборка и запуск

```sh
make
sudo ./joy-for-msfs2020
```

Программе нужны права на чтение `/dev/input/event*` и запись в `/dev/uinput`
(подробнее — в `AGENTS.md`).

## Кнопки управления

Раскладка — Numpad. Одно нажатие двигает ось на шаг, сброс возвращает ось
в центр. У тяги сброса нет.

- X — уменьшить `4`, сброс `5`, увеличить `6`
- Y — уменьшить `8`, сброс `7`, увеличить `2`
- Z — уменьшить `1`, сброс `7` или `0`, увеличить `3`
- Тяга — уменьшить `Enter`, увеличить `+`

Клавиша `7` сбрасывает одновременно Y и Z. Остальные клавиши Numpad
не задействованы.

## Проверка

После запуска программы в отдельном терминале:

```sh
jstest-gtk
```

Выбрать устройство `joy-for-msfs2020` и нажимать клавиши Numpad: оси должны
двигаться шагами, а положение сохраняться, пока работает программа.
